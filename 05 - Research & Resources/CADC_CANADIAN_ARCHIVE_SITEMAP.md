## 2. ☄️ Highlight Service: SSOIS (Solar System Object Image Search)

The **Solar System Object Image Search (SSOIS)** is a specialized astronomical search service created by CADC to locate images containing moving solar system bodies (asteroids, comets, Kuiper Belt Objects, Centaurs, and hypothetical bodies like Planet X).

### Three Search Modalities:
1. **Search by Object Name:** Resolves names through the Minor Planet Center (MPC) or JPL Horizons (e.g. `(3200) Phaethon`, `C/2020 F3`, `Sedna`).
2. **Search by Arc Extrapolation:** Given known RA, Dec, and daily motion rates ($d\alpha/dt, d\delta/dt$), SSOIS computes orbital tracks and returns intersecting exposures.
3. **Search by Orbital Elements:** Input keplerian orbital elements ($a, e, i, \Omega, \omega, M$) to search for historical pre-discovery ("precovery") plates.

### Intersected Archives:
SSOIS searches across CFHT (MegaCam, WIRCam), Gemini North/South, HST, NEOSSat, and DAO, returning exact pixel coordinates $(x, y)$ where the object is predicted to appear on each astronomical FITS plate.

## 3. 🌐 Common Archive Observation Model (CAOM-2) & TAP Architecture

CADC pioneered **CAOM-2**, the international standard data model that unifies observations across diverse telescopes into an identical relational schema.

### Core Tables in `caom2`:
- **`caom2.Observation`**: High-level exposure metadata (`observationID`, `collection`, `instrument_name`, `target_name`, `time_bounds_lower`, `spatial_bounds`).
- **`caom2.Plane`**: Specific processed data products (raw, calibrated, mosaic) with calibration level, data release, and energy bandpass.
- **`caom2.Artifact`**: Direct FITS file access URLs (`access_url`), content types, and file sizes.

### Sample TAP ADQL Query via Python:
```python
from astroquery.cadc import Cadc

cadc = Cadc()

# ADQL query searching for NEOSSat observations overlapping a target field
query = """
SELECT TOP 50
    observationID, target_name, time_exposure,
    spatial_bounds, access_url
FROM
    caom2.Observation
WHERE
    collection = 'NEOSSAT'
    AND time_exposure > 60.0
ORDER BY
    time_bounds_lower DESC
"""

results = cadc.query_exec(query)
print(f"Retrieved {len(results)} CADC records.")
for row in results[:5]:
    print(f"Obs: {row['observationID']} | Target: {row['target_name']}")
```
